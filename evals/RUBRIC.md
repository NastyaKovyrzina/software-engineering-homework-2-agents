# Ручная оценка

В `runs/evals/<ID>/manual.csv` оцените ответ по снимку `<case_id>-<turn>.json`:

- Правильность и полнота: 0 — нет, 1 — частично, 2 — полностью.
- Подтверждение источником и соблюдение инструкции: да/нет.
- Правки: нет, небольшие, существенные; замечания поясните.

Пустые поля остаются непроверенными. После заполнения выполните из корня:

```powershell
.\.venv\Scripts\python.exe eval_system.py --report runs/evals/ID
```

Замените `ID` именем папки прогона. Настоящая цитата, не отвечающая на вопрос, не считается правильным ответом.
