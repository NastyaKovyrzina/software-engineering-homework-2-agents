# Структура проекта

| Путь | Содержимое |
|---|---|
| `app.py`, `run_sandbox.py` | Приложение и запуск в Sandboxie |
| `model_gateway.py`, `configure_sandbox.py` | Шлюз моделей и правила песочницы |
| `lecture_assistant/` | Граф, инструменты, память, клиент моделей и телеметрия |
| `instructions/` | Ролевые промпты, навыки и общий контекст |
| `data/lectures/` | Лекции UTF-8 `.txt`/`.md` |
| `models.json`, `router_settings.json` | Модели и настройка классификатора |
| `web/` | Русскоязычная панель |
| `tests/`, `evals/` | Модульные тесты и оценочные сценарии |
| `scripts/` | Подготовка NLI-модели |
| `docs/diagrams/` | C4, Sequence и схема графа |
| `runs/`, `results/` | Память, журналы, оценки и сохранённые ответы |

Все команды запускаются из корня проекта. Абсолютный путь к скачанной папке в инструкциях не требуется.
