# Повторные проверки

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe regression_checks.py check
.\.venv\Scripts\python.exe regression_checks.py watch
```

`check` запускает модульные тесты без LLM. `watch` повторяет их после изменения кода, тестов, инструкций, настроек и оценочного набора. Изменение журналов повтор не вызывает. Вывод и SHA-256 файлов сохраняются в `runs/checks/`; изменение исходников во время проверки отмечается.

[Evals](EVALS.md) с реальными моделями запускаются отдельно; сохранённые полные прогоны можно сравнить. Непрерывный контроль доступности и порогов ресурсов работает вместе со [службой наблюдения](OBSERVABILITY.md).

Пример прежнего исправления: c30 с пустым вопросом не доходил до ожидаемой проверки входа. Запускатель стал отличать пустую строку от отсутствия аргумента. Повтор c30 через Sandboxie прошёл с ожидаемой ошибкой, без вызовов LLM. Это исторический результат; новые прогоны сохраняются отдельно.
