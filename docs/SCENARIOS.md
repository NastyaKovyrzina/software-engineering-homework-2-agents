# Проверочные сценарии

Текущий набор — `evals/dataset.json`: прямые вопросы, отсутствие сведений, инструкции в документе, память, маршрутизация и неверный вход.

Один реальный сценарий из корня, при работающем шлюзе:

```powershell
.\.venv\Scripts\python.exe eval_system.py --mode sandbox --case c01
```

Ожидаемый отказ или ошибка входа засчитываются при совпадении с условиями случая. Переходы исправления и ошибки инструментов дополнительно покрываются модульными тестами.
