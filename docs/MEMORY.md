# Память

Состояние графа передаёт данные внутри запроса. Между запусками используется SQLite: `runs/memory/assistant.sqlite3`.

| Слой | Содержимое |
|---|---|
| Беседа | Вопросы, ответы, статусы и версия лекции; в контекст идут до трёх предыдущих вопросов |
| Задача | Снимки этапов, фрагментов, черновика и проверок; для просмотра, без автоматического возобновления |
| Долговременные записи | Одобренные цитаты с источником, версией и датами |

Прошлые ответы не используются как источники. Цитаты перед повторным использованием сверяются с текущей лекцией. История, задачи и цитаты хранятся 30 дней; кеш поиска — один день. Смена версии файла исключает старые сведения из текущего поиска.

## Почему SQLite

| Подход | Ограничение для этой задачи |
|---|---|
| Простой RAG | Как единственная память неоптимален: не ведёт историю, состояние задачи и правила актуальности |
| Улучшенный RAG, LlamaIndex, PageIndex | Улучшают извлечение, но не заменяют управление историей и сроками хранения |
| LangMem | Автоматическое извлечение памяти требует дополнительных вызовов и проверки |
| SQLite | Явные связи, версии и сроки без отдельного сервера; схему и очистку приходится поддерживать самим |

## Управление

```powershell
.\.venv\Scripts\python.exe memory_cli.py stats
.\.venv\Scripts\python.exe memory_cli.py notes
.\.venv\Scripts\python.exe memory_cli.py history --session demo
.\.venv\Scripts\python.exe memory_cli.py forget-session --session demo
.\.venv\Scripts\python.exe memory_cli.py clear-cache
.\.venv\Scripts\python.exe memory_cli.py prune
```

`forget-session` удаляет записи беседы из SQLite, `clear-cache` — общий кеш, `prune` — просроченные записи. Файлы `runs/` и `results/` этими командами не удаляются. Для запроса без памяти используйте `--no-memory`.
