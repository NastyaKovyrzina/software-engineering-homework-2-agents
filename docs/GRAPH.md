# Граф обработки

Запуск — из корня проекта по [README](../README.md).

`lecture_assistant/lecture_graph.py` задаёт управляемый граф LangGraph:

1. Чтение лекции и версии файла.
2. Qwen2.5 формулирует поисковый запрос; Python ищет фрагменты.
3. Классификатор выбирает простую или сложную модель автора.
4. Автор выбирает дословные цитаты со ссылками.
5. Python проверяет источники и цитаты, Gemma — ответ на вопрос.
6. При замечаниях выполняется одно исправление и повторная проверка.
7. Подтверждённый ответ сохраняется; иначе возвращается отказ или техническая ошибка.

Координатор реализован кодом. Роли поиска, ответа и проверки обмениваются общим состоянием; вызовы моделей последовательны и выполняются на CPU. Семейство проверяющей модели отличается от семейства автора.

Ответ содержит только дословные цитаты. Сравнения и причины можно показать, если они явно отражены в найденном тексте; свободный пересказ не реализован.

Остановка: не более одного исправления; неустранимые ошибки завершают запрос. Нет совпадений или одобрения — `insufficient_information`, подтверждённый ответ — `answered`, технический сбой — `technical_error`.
