# Evals

`evals/dataset.json`: 30 сценариев, 33 обращения; три сценария проверяют память двумя вопросами. Ожидания заданы заранее. Запуск — из корня при работающих Ollama, шлюзе и Sandboxie:

```powershell
.\.venv\Scripts\python.exe eval_system.py --mode sandbox
```

Для одного случая добавьте `--case c01`. `--mode gateway` — отладка вне песочницы, не проверка изоляции.

| Метрики | Проверяется |
|---|---|
| Продукт | Успех сценариев, корректные отказы, необходимость ручных правок |
| Ответы | Нужные факты, дословность и источник цитат, соблюдение инструкций |
| Агенты | Маршрут, ошибки инструментов/моделей, исправления и переходы |
| Инфраструктура | Время, CPU, RSS помощника и доступные токены |

В `runs/evals/<ID>/`: `report.md`, `report.json`, `results.csv`, `manual.csv`, снимки и журналы. `run_id` связывает результат с трейсом. RSS не включает Ollama; неизвестные метрики не считаются нулями.

Заполните `manual.csv` по [рубрике](../evals/RUBRIC.md), затем обновите отчёт. Для примеров ниже замените `ID`, `NEW`, `OLD` именами папок:

```powershell
.\.venv\Scripts\python.exe eval_system.py --report runs/evals/ID
.\.venv\Scripts\python.exe eval_system.py --report runs/evals/NEW --compare runs/evals/OLD
```

Сравнение не вызывает модели; нужны полные прогоны текущего формата с одинаковым набором, оценщиком и режимом. Результат — `comparison.json`; ухудшения создают оповещения.

Ожидаемая техническая ошибка может означать успешный тест. Код завершения 1 означает, что не все проверки пройдены. Gemma внутри графа не является независимым LLM-as-a-Judge; ручная оценка учитывается отдельно.
