# Требования и реализация

| Требование ТЗ | Реализация |
|---|---|
| Несколько локальных LLM | Четыре модели в `models.json`, сервер Ollama |
| Общий многоагентный процесс и фреймворк | LangGraph, `lecture_assistant/lecture_graph.py` |
| Архитектура и проверяющий другого семейства | Последовательный граф с маршрутом; Qwen — автор, Gemma — проверяющий |
| Маршрутизация и Jev-like | Отдельный NLI MiniLM; `router_worker.py`, `router_settings.json` |
| Промпты, skills и содержательные Markdown | `instructions/`, `manifest.json`, `instruction_loader.py` |
| Инструменты и валидация | `lecture_assistant/lecture_tools.py`, сверка источников и цитат |
| Ограниченные повторы | Одна попытка исправления, условные переходы и остановка |
| Три слоя памяти и актуальность | SQLite, версии лекций, перепроверка цитат, сроки 1/30 дней |
| Изолированный запуск | Sandboxie, ограниченный шлюз и `run_sandbox.py --check` |
| Evals и четыре категории метрик | `evals/dataset.json`, `eval_system.py`, ручная рубрика |
| Связь оценки с трейсами | `run_id` и метаданные Evals |
| Логи, метрики, трейсы, траектории и алерты | `telemetry_*`, русская панель, Phoenix |
| Повторные проверки и мониторинг | `regression_checks.py check/watch`, служба наблюдения |
| Семь C4 и отдельная Sequence | Восемь изображений в `docs/diagrams/` |

Сравнение движков, моделей, изоляции, архитектур и фреймворков оформляется в отчёте по экспериментам. Наличие компонента не гарантирует правильность ответов. Jev-like здесь — функциональная аналогия; свободный пересказ в MVP не реализован.
