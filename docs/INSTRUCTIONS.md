# Промпты, навыки и контекст

| Каталог | Назначение |
|---|---|
| `instructions/roles/` | Постоянные обязанности поиска, автора и проверяющего |
| `instructions/skills/` | Шаги поиска, ответа, проверки и одного исправления |
| `instructions/context/` | Правила проекта, источников и памяти |

`instructions/manifest.json` связывает файлы с этапами. `InstructionSnapshot` из `lecture_assistant/instruction_loader.py` читает их при построении графа и сохраняет контрольные суммы в метаданных выполнения.

Общий контекст получают все LLM-роли; каждая получает свой промпт и навык. Исправление использует роль автора и навыки ответа/исправления. Лекция и вопрос считаются данными, их содержимое не меняет инструкции.
