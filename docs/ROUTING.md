# Маршрутизация

| Роль | Модель |
|---|---|
| Поиск | Qwen2.5-0.5B (`se-qwen05:latest`) |
| Простой ответ | `qwen3:0.6b-q4_K_M` |
| Сложный ответ | `qwen3.5:2b-q4_K_M` |
| Проверка | `gemma3:1b-it-q4_K_M` |

`--route auto` использует отдельный NLI-классификатор `MoritzLaurer/multilingual-MiniLMv2-L6-mnli-xnli`, INT8 ONNX на CPU. Версия, каталог весов, описания классов и порог заданы в `router_settings.json`.

- `simple`: отдельный факт, дата, название или определение.
- `complex`: сравнение, причины или объединение сведений.

Классификатор возвращает класс и числовые оценки, а не ответ пользователю. Это функциональный Jev-like аналог, не сама Jev; его оценки не являются откалиброванными вероятностями правильности.

В Sandboxie классификация идёт через шлюз, вне неё в режиме direct — через локальный процесс. При сбое классификатора выбирается `complex`; отсутствие малой модели также допускает переход на большую. Оба автора возвращают цитаты.

Ручной маршрут: добавьте `--route simple` или `--route complex` к запуску вопроса. Отдельная оценка классификатора:

```powershell
.\.venv\Scripts\python.exe eval_system.py --router
```
