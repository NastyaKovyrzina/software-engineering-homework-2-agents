# Инструменты

Реализация: `lecture_assistant/lecture_tools.py`. Лекция выбирается при создании `LectureTools`; имя берётся из `data/lectures/`.

| Инструмент | Аргументы | Результат |
|---|---|---|
| `read_lecture` | Нет | Читает лекцию, готовит фрагменты; возвращает имя, версию и размеры |
| `search_fragments` | `query`, `limit` (1–5) | Фрагменты по совпадениям слов со сведениями об источнике |
| `get_quote` | `fragment_id`, `quote` | Проверенная дословная цитата и её строки |
| `save_result` | `question`, `answer`, `citations` | JSON в `results/` и сведения о сохранении |

Аргументы проверяются кодом; модель не выбирает путь записи. Источник содержит имя файла, SHA-256 версии, раздел, строки и смещения.

Ограничения: UTF-8 `.txt`/`.md` до 2 МиБ; лексический поиск не понимает синонимы. Смена файла требует повторного чтения.

Ошибки возвращаются как `ok: false` с кодом: например `FILE_NOT_FOUND`, `EMPTY_DOCUMENT`, `INVALID_ARGUMENT`, `STALE_DOCUMENT`, `QUOTE_NOT_FOUND`, `IO_ERROR`. Отсутствие совпадений — нормальный результат поиска.

`save_result` сверяет цитаты, но не оценивает смысл; содержательную проверку отдельно выполняет граф с Gemma. Проверки инструментов: [CONTINUOUS_CHECKS.md](CONTINUOUS_CHECKS.md).
