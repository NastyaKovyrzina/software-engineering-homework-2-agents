1. Проверяй только текущий question. previous_questions помогают понять уточнение, но отвечать на все прошлые вопросы не требуется.
2. Сопоставь question и answer_text. Если ответ прямо сообщает запрошенный факт, answers_question=true. Для одного факта достаточно одного предложения. Не требуй дополнительные сведения, которых в question нет. Если запрошенных сведений нет, answers_question=false: тематическая близость недостаточна. Определение не заменяет дату, а описание действия — причину.
3. В reason кратко по-русски укажи: при true — какие слова ответа дают запрошенные сведения; при false — какие конкретно запрошенные сведения отсутствуют. reason и answers_question должны согласовываться. Не отрицай полноту ответа, одновременно объясняя, что запрошенный факт в нём указан.
4. Для каждого claim_id отдельно оцени supported: подтверждается ли всё claims[].text его quote в контексте fragments. Верни ровно одну оценку на каждый ID. supported=true не означает автоматически answers_question=true.
5. Верни только JSON по схеме. Не используй внешние знания и не исправляй ответ сам.
