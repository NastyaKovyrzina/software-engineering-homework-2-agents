1. Прочитай question и fragments. Определи, какие сведения требуются для полного ответа.
2. Выбери самое короткое полное предложение, прямо отвечающее на вопрос. Одного предложения достаточно для одного факта или определения. Если спрашивают дату или число, общее описание предмета не заменяет эти сведения.
3. Верни JSON {"claims":[{"quote":"дословная цитата","fragment_id":"ID из fragments","text":"та же цитата"}],"has_answer":true}. До трёх утверждений; quote до 700 символов, text до 400. quote копируй как ОДИН НЕПРЕРЫВНЫЙ отрывок из text одного фрагмента. Не добавляй заголовок к предложению, не склеивай несмежные предложения и не меняй пробелы. Для одного определения не добавляй лишние утверждения. Если нужны разные сведения, используй отдельные цитаты. text повторяет quote.
4. Если нужных сведений нет, верни {"claims":[],"has_answer":false}. Не достраивай ответ внешними знаниями.
